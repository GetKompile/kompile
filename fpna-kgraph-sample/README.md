# FPNA KGraph Sample

Throwaway standalone Maven project for exercising `kompile-graph-reasoning` with a manually curated FPNA graph.

## Source Data Used

The sample is hand-built from these local FPNA fixtures:

- `kompile-fpna-v4/project/src/test/resources/fpna-expected-graph.html`
- `kompile-fpna-v4/project/src/test/resources/fpna-business-process-crawl-results.html`
- `kompile-fpna-v4/project/src/test/java/ai/kompile/fpna/v3/FpnaEntityExtractionTest.java`
- `kompile-fpna-v4/project/src/test/java/ai/kompile/fpna/v3/FpnaCrawlGraphExtractionTest.java`
- `kompile-fpna-v8/data/graph/1/graph-extraction-checkpoints.json` for generated crawl context only

The graph is deliberately not generated by a crawler. It manually adds canonical people, emails, spreadsheets, forecasts, tables, channel taxonomy nodes, close steps, controls, observed crawler-like relationships, crawler-style semantic embeddings, and a few derived relationships useful for reasoning trace experiments.

## Run

If the local snapshot dependencies are not already installed, install the graph reasoning and process discovery modules from the repo root first:

```bash
mvn -pl kompile-app/kompile-data/kompile-graphs/kompile-graph-reasoning,kompile-app/kompile-data/kompile-process/kompile-process-discovery -am install -DskipTests
```

Then run the sample:

```bash
cd fpna-kgraph-sample
mvn package exec:java
```

The default output is:

```text
target/fpna-pristine-sample.kgraph
```

You can pass a custom output path:

```bash
mvn exec:java -Dexec.args=/tmp/fpna-pristine-sample.kgraph
```

Run the deduction experiment driver against the same hand-built graph:

```bash
mvn package exec:java -Dfpna.mainClass=ai.kompile.samples.fpna.FpnaDeductionExperiment
```

The deduction run writes:

```text
target/fpna-deduction-results.kgraph
```

That archive contains `deduction-report.md`, `deduced-facts.jsonl`, `deduction-fact-base.txt`, `hybrid-ranking.tsv`, `hybrid-vector-layer.md`, `process-derivation-gap-report.md`, and `process-entailment-spotting-eval.tsv` artifacts.

## Business Process Generation Evaluation

Run graph-only process generation and evaluate the ranked output against the nine-process FPNA gold rubric:

```bash
mvn package exec:java -Dfpna.mainClass=ai.kompile.samples.fpna.FpnaBusinessProcessGeneration
```

Generation runs before the evaluator constructs the gold rubric. The production generator receives only the `UnifiedGraph`; gold names, concepts, and order constraints are used only for post-generation scoring.

The current fixture run contains 152 entities and 167 relations. It attempts 48 graph projections, retains 34 ranked candidates, and spots 9/9 gold processes under the documented entailment-aware threshold. The initial generic baseline spotted 5/9, with three partial and one missed process.

The 9/9 result is threshold recall, not perfect extraction. Variance triage has 87.5% concept recall, regional submission has 62.5%, ontology evolution has 75%, and the monthly close has 77.8% expected-order recall. Candidate precision and duplicate granularity still need a separate evaluation.

The run writes:

```text
target/fpna-business-process-generation.kgraph
target/fpna-process-generation-report.md
target/fpna-process-generation-coverage.tsv
target/fpna-process-generation-candidates.tsv
```

The generated `.kgraph` also stores ranked process suggestions and canonical reasoning traces for each retained candidate.
