Reactive graph rules

A reactive rule watches the live knowledge graph and fires an action (write a log entry or call a webhook) whenever a matching change occurs — for example, "notify my pipeline whenever a crawl creates more than 50 new nodes."

Rules are evaluated automatically by the change-tracking hook after each changeset or individual mutation. They are not the same as probabilistic inference rules — those auto-generated soft-logic (PSL/FOL) rules live in the FOL Rules tab and are managed separately.
