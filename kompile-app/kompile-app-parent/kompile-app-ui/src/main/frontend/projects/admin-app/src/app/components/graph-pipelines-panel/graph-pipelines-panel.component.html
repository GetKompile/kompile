hub Channel Pipelines connect live channels (Slack, email, webhooks, …) directly to your knowledge graph. When a matching message arrives it is processed immediately — no full crawl needed. Each pipeline listens on one or more channels, optionally filters by sender or content, then runs a set of steps (e.g. entity extraction) into a target fact sheet.
