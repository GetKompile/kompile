psychology PSL Program

This graph reasons with a Probabilistic Soft Logic (PSL) program — a set of weighted if-then rules over soft-truth values in [0, 1]. Each rule has the form weight: body → head. The solver finds the assignment of truth values that best satisfies all rules simultaneously (MAP inference).

A rule's weight expresses how strongly it is trusted: a higher weight pulls the solution harder toward satisfying that rule. Weights are learned online every cascade — the bar beside each rule shows its current learned strength relative to the strongest rule in the program.
