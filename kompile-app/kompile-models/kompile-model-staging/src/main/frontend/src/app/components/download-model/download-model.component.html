Complete accelerator chat model

Produces a target-compiled .sdz with tokenizer.json, tokenizer configuration, chat template, and generation configuration. Import it through the Android model picker. It deliberately contains no knowledge graph or Markdown.

Full offline graph-chat project

Wraps the same complete .sdz with a validated graph and Markdown copied from the synced server project. The server must configure kompile.staging.project-dir; staging fails clearly if the project is missing, invalid, or has not synced its graph and Markdown.
